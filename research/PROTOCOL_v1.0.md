日期:2026-10-02 · 作者:项目作者(待填) · 注册:待注册(OSF / PROSPERO)

## 1. 背景与理由(作者表述的整理,非文献结论)

作者希望用患者肿瘤的多组学数据,在已知信号通路先验之上推断带反馈的稳态调控网络,新边须由数据支撑,不使用扰动数据或时间序列。作者不确定该方向是否已有人做过。本回顾先回答"已有工作做到哪一步"。本协议**不预设**该方向新或不新。

## 2. 综述问题(作者于 2026-10-02 选定"候选 1+2+3 结合";措辞为 AI 起草)

在使用患者肿瘤横断面多组学数据(不含扰动或时间序列)、并利用通路先验推断信号调控网络(含反馈结构)的研究中:
- **Q1 方法**:用了哪些方法与数据层?
- **Q2 验证**:如何验证推断出的边或反馈环,报告了什么结果?
- **Q3 可识别性**:是否明确陈述或检验了从横断面数据识别反馈/方向性所需的假设,依赖什么?

## 3. 框架(PICOS 的方法学改写)

| 要素 | 内容 |
|---|---|
| 对象 | 肿瘤患者样本的多组学数据集(≥2 个分子层,如突变/CNA/RNA/蛋白/磷酸化) |
| 暴露/方法 | 推断信号或调控网络、且使用通路先验或已知相互作用的计算方法 |
| 对照 | 无(描述性综合) |
| 结局 | 见第 6 节数据项 |
| 设计 | 方法学论文与应用论文 |

## 4. 纳入与排除标准

| 项目 | 纳入 | 排除 |
|---|---|---|
| 数据 | 人肿瘤组织的横断面多组学 | 仅细胞系、仅动物、仅单一分子层 |
| 方法 | 网络/通路层面推断,含方向或符号 | 仅差异表达、仅聚类、仅通路富集 |
| 先验 | 明确使用通路或相互作用先验 | 完全无先验的纯统计相关网络 |
| 扰动/时序 | 主分析数据为横断面 | 以扰动实验或时间序列为主要推断依据(可作为附表登记) |
| 癌种 | 不限癌种(UCEC 另做亚组标注)`[待确认]` | — |
| 时间 | 2010 年至今 | 更早 |
| 语言 | 英文、中文 | 其他 |
| 类型 | 同行评审论文、预印本;会议摘要不纳入 | 评论、社论 |

## 5. 信息源与检索

PubMed、Web of Science、Scopus、arXiv/bioRxiv、IEEE Xplore(计算方法);反向与正向引文追踪。检索式在冻结前经 PRESS 自检,记录日期与命中数。灰色文献:GitHub 方法库仅作线索,不计入纳入。

检索概念块(草案):
1. 肿瘤/癌症 AND 多组学 / proteogenomic / phosphoproteomic
2. 信号网络 / regulatory network / pathway / signalling network
3. 推断 / inference / reconstruction / learning
4. 先验 / prior knowledge / knowledge-guided / pathway-informed
5. 反馈 / feedback / cyclic / directed

## 6. 数据项

- 元数据:作者、年份、癌种、队列、样本量
- Q1:方法类别(线性/贝叶斯/因果发现/图神经网络/ODE 等)、数据层、先验来源、是否允许反馈/环
- Q2:验证类型(留出、独立队列、文献已知边、湿实验、模拟)、对照/基线、报告的指标与数值
- Q3:是否陈述识别假设、假设内容、是否检验、对横断面限制的讨论

## 7. 筛选与提取

标题/摘要、全文两阶段。**局限须声明:主要由 AI 辅助的单一筛选者完成,作者抽查;不满足"双人独立"。** 排除原因全程记录。

## 8. 质量/偏倚评估

RoB 2、ROBINS-I 不适用于方法学论文。提议改用自制清单:验证是否独立于训练;是否有基线;是否报告失败或负结果;是否开放代码与数据。

## 9. 综合方法

叙事性综合,按 Q1/Q2/Q3 列表与证据地图。不做 meta 分析。证据确定性不用 GRADE。

## 10. 偏倚与局限(预先声明)

发表偏倚(负结果少见);术语不统一导致漏检;AI 单筛选者;检索仅覆盖所列数据库。
